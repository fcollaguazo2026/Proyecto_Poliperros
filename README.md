Proyecto POLI - Sistema de Pedidos
Este proyecto es un sistema de gestión de pedidos desarrollado en Python. Permite registrar, mostrar, actualizar y eliminar pedidos de manera sencilla, almacenando información tanto del cliente como del destinatario.
El sistema utiliza listas para organizar los datos de cada pedido, incluyendo nombre, apellido, teléfono, información del destinatario, código de pedido y tipo de repartidor con su respectivo costo. Además, genera un código aleatorio para cada pedido y permite visualizar los datos de manera tabular mediante la librería PrettyTable.
Entre sus funcionalidades principales se encuentran:

Registro de pedidos con información de cliente y destinatario.
Visualización de pedidos en consola y en formato de tabla.
Eliminación de pedidos mediante su código único.
Posibilidad de actualizar los pedidos (pendiente de implementación).
El sistema está diseñado para ser ejecutado en consola y proporciona una interfaz interactiva para el usuario mediante menús y entradas por teclado.
